# Work-Setu

Work-Setu is a full-stack platform designed to connect users with work opportunities, task management, urgent service tracking, and AI-powered features. The project includes a modern frontend, backend APIs, and AI model integration.

## 🚀 Features

- User Authentication & Authorization
- Admin Dashboard
- Job Posting & Scheduling
- Work Tracking System
- Wallet & Payment Integration
- Notification System
- Socket.IO Real-time Communication
- AI Matching / Recommendation Features
- Protected Routes
- Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- Socket.IO Client

### Backend
- Node.js
- Express.js
- MongoDB
- Socket.IO
- JWT Authentication

- Python
- Machine Learning Models
